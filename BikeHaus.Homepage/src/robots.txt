# DIESE SEITE IST BEWUSST AUS SUCHMASCHINEN UND KI-ANTWORTEN
# GENOMMEN.
#
# Zwei Gruppen, zwei verschiedene Mittel — das untenstehende
# `Disallow: /` fuer die KI-Crawler widerspricht dem `Allow: /` hier
# also NICHT, siehe den eigenen Abschnitt weiter unten.
#
# Fuer Suchmaschinen (Google, Bing) bleibt das Crawlen ERLAUBT — und das ist kein Widerspruch, sondern
# Voraussetzung: Entfernt wird eine Seite ueber `noindex`, und diesen
# Hinweis liest Google nur, wenn es die Seite abrufen DARF. Ein
# `Disallow: /` wuerde den Abruf unterbinden, der noindex nie
# ankommen und bereits indexierte Seiten blieben auf unbestimmte Zeit
# in den Ergebnissen stehen — das Gegenteil des Gewollten.
#
# Der noindex kommt aus drei Quellen, alle an einem Schalter:
#   - src/index.html (robots-Meta, Ausgangswert jeder Route)
#   - src/app/services/search-indexing.ts (robotsFor(), Komponenten)
#   - nginx/nginx.conf (X-Robots-Tag, auch Dateien und Bilder)
#
# Die Sitemaps bleiben absichtlich eingetragen: sie sind jetzt die
# Abrufliste, ueber die Google die noindex-Seiten wiederfindet und
# aus dem Index nimmt. In der Search Console erscheinen dadurch
# erwartbar "Durch noindex-Tag ausgeschlossen"-Meldungen — genau das
# ist der Fortschritt, kein Fehler.
#
# Zurueckdrehen und naechste Schritte: SEO-DEINDEX.md im Repo-Root.
# ─────────────────────────────────────────────────────────────────

# KI-/LLM-CRAWLER: AUSGESCHLOSSEN
#
# Die Seite soll auch in KI-Antworten nicht mehr auftauchen —
# ChatGPT, Claude, Perplexity, Gemini, Copilot & Co.
#
# Hier ist `Disallow: /` das RICHTIGE Mittel, anders als bei Google
# und Bing weiter oben. Der Unterschied: ein Suchindex muss geleert
# werden, und dazu muss Google die Seite abrufen und den noindex
# lesen duerfen. Diese Crawler fuehren keinen Index, aus dem etwas
# zu entfernen waere — sie holen Text fuer Training und fuer die
# Antwort im Moment der Frage. Ihr dokumentierter Opt-out ist
# robots.txt, ein noindex-Meta beachten sie nicht. Also: Tuer zu.
#
# Googlebot und Bingbot bleiben deshalb bewusst ERLAUBT (oben,
# `User-agent: *`): sie brauchen den Abruf, um den noindex zu sehen.
# Dass die Seite danach aus Googles AI Overviews und aus Bing
# Copilot verschwindet, folgt automatisch — beide stuetzen sich auf
# den Suchindex, und daraus fliegt sie heraus. Google-Extended
# (Gemini-Grounding, Training) ist zusaetzlich separat zu.
