---
description: Run the admin SPA dev server (BikeHaus.Client)
---

Run `npm start` in `BikeHaus.Client/` in the background. The Angular dev server listens on http://localhost:4200. Watch for "Compiled successfully" or the first compilation error and report it. The API at http://localhost:5196 must be running for the SPA to be usable — remind the user if it isn't.
